# 내 퀴즈 주제

주제: 서울에 눈은 얼마나 오나
고른 이유: 다들 요즘 눈이 줄었다고 하는데, 실제로 세어 보면 다를 것 같다.
제목: 서울에는 눈이 얼마나 오나

출처: Open-Meteo 과거 날씨 API · ERA5 (https://open-meteo.com/en/docs/historical-weather-api)
고른 이유: 키 없이 받을 수 있고, 서울의 하루 강설량이 1990년부터 있다. 링크를 열어 확인했다.

세는 기준
- 눈 온 날 = 하루 강설량 1cm 이상
- 첫눈은 겨울 시즌 기준으로 센다
- 비교: 1990~1999년과 2015~2024년 — 한 해 눈 온 날 5.1일 → 4.2일 (0.82배, «조금 줄었다»)
- 주의: 연도별로 흔들림(약 3일)이 변화폭(0.9일)보다 크다. 2cm 이상으로 세면 «거의 같다»가 된다
